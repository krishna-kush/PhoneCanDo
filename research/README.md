# research/

Background notes and open questions. Nothing here is shipped, and nothing
here is a roadmap. Product shape lives in
`../docs/overview/architecture.md`.

This folder naturally bloats while a question is being explored, then thins
out and gets structured as the work moves on: settled material graduates into
the various docs (`docs/`, `app/docs/`) or the code, and only unresolved
background stays here. A thin folder is expected, not a gap.

- `open-questions.md` — scope questions that are not scheduled.
